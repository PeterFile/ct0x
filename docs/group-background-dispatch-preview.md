# 群组后台讨论：本机预览

默认关闭。只有 SQLite 已安装后台调度迁移、且本机操作者显式提供授权文件和受支持的 Pi 路径时，才可通过普通 `workspace` 启动入口选择此预览：

```sh
workspace --enable-execution --pi-path /trusted/bin/pi \
  --group-background-dispatch-preview /trusted/a1-approval.json
```

授权文件必须是本机可信的 0600 或 0400 普通文件（非符号链接，最多 16 KiB）。文件、Pi 路径及其上级目录必须由操作者控制，包括实际的 CLI 配置；不得放进已授予 Agent 写入权限的目录。用原子替换更新文件。不要写入凭据、个人认证配置、聊天内容或模型输出。

授权文件显式指定一个提供方 ID（`/api/v1/providers` 中所选 `--pi-path` 的 ID）、一个无歧义的精确 Pi 模型选择器、批准截止时间、每群活跃成员上限（1..200）以及一个讨论预设。`preset` 要提供 `id`、`name`、`role`；不从开发配置、现有成员、协调策略或模型正文推断批准。优先重用符合该模型配置且无外部工作区的现有成员；有容量时才使用预设，不另行临时创建。全局执行并发仍由 `--execution-max-active` 决定。

| 字段 | 说明 |
| --- | --- |
| `provider_id`, `model`, `max_active_members`, `approval_expires_at`, `preset` | 明确的预览授权。时间使用 RFC 3339。 |
| `paused` | 可选，设为 `true` 暂停后台调度。 |
| `qualification` | 可选。仅由可信操作者根据一次实际成功的无工具全新 Pi 单轮写入。字段为 `provider_id`、`model`、`path`（与目录中的选定路径相同）、`version`、`transport`（`pi_one_shot`）及 `observed_at`（实际观测时间，RFC 3339）。必须与批准和实际适配器完全匹配；仅使用过去 30 秒内的观测，不用文件修改时间刷新。 |

只读版本／登录检查、适配器能力和现有通用轮次回执不是此证据。预览只消费可信操作者提供的短期声明；它不检查实际账号是否更换，也不证明账号、网络或模型当前可用。声明必须来自原 CLI 的同一账号、端点和精确模型的实际运行；路径、版本、启动环境以及账号配置须保持不变，否则应撤回声明。代码库尚无生产证据来源，能绑定这些事实并在失效时撤回；不能据此默认开启预览。启动与调度均不会为发现模型而运行付费探针。

每个既有调度周期在认领前重新读取。文件撤回、暂停、授权或证据到期、绑定不匹配、Pi 不可用或配置无效时，一旦采样即移除就绪；已认领执行不会因此被取消或释放资源。缺少合格证据时，新绑定群的省略收件人消息仍保存并等待，不走旧默认路由。省略启动参数可在重启时停用；之前绑定的群仍保存这类请求，明确指定收件人的普通投递继续走原执行路径。旧群不回填绑定，仅公开消息不唤醒模型。
