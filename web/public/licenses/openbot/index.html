本地适配范围

  • WorkspaceFrame.tsx：11–39、62–103 行：保留左区、面板和内容槽位的绘制次序；改为 React 类型化属性，移除 Solid、Electron、远程连接及新页面运行时。
  • SidebarFrame.tsx：1–16 行：保留 aside 及 sidebar/panel-edge 结构，接入原有群组和中文标题。
  • PageRail.tsx：24–43、381–434 行：保留按钮属性及导航分组，用原生按钮和中文文字替换上游 UI 库、品牌与图标；仅连接真实群组、聊天、搜索、成员、任务操作。
  • page-rail.css：1–14、47–92 行、app-shell.css：24–46、848–854、867–887、3347–3350 行、web-client.css：61–97、112–130、274–278 行：提取使用到的结构、表面、交互与单面板规则；作用域限定为 .openbot-shell，映射本产品色彩与字体，使用现有 56rem 断点与可见性状态。
